# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates the interest earned on a principal amount based on the given interest rate and time period.

## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest per year
- T = Time period in years

## Example

If:
- Principal = 10,000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (10,000 × 5 × 2) / 100

Simple Interest = 1,000

Total Amount = Principal + Simple Interest

Total Amount = 11,000

## Features
- Takes principal amount as input
- Takes annual interest rate as input
- Takes time period as input
- Calculates simple interest
- Calculates total amount

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Click the Calculate button.
5. The simple interest and total amount will be displayed.
